# Primary research and context (accessed 2026-10-27)

1. Bellibatlu, R. R., Wang, Z., Zhang, W. (2026-09-29). *Do Agent Benchmarks Do What They Say? An Executable-Contract Audit of Tool-Using Agent Environments*. https://arxiv.org/abs/2609.37315 — motivates executable contracts and state-based oracles. The paper's findings are **not** results from ContractTrace.
2. Zhu, Z. et al. (2026-10-06). *HarnessSecurity-Bench: Do Security Mechanisms Really Protect Coding Agent Harnesses?* https://arxiv.org/abs/2610.07639 — motivates independent task utility and security outcome checks.
3. Stanford HAI (2026). *AI Index Report 2026*, section 2.6 agent benchmarks. https://hai.stanford.edu/assets/files/ai_index_report_2026.pdf — evidence of tool-use reliability gap in airline/retail-style tasks.
4. Yang, C. et al. (2026-05-06). *AgentTrust: Runtime Safety Evaluation and Interception for AI Agent Tool Use*. https://arxiv.org/abs/2605.04785 — runtime interception concept; ContractTrace does not reproduce AgentTrust's reported scores.
5. SQLite documentation: Transactions, isolation and WAL. https://www.sqlite.org/isolation.html — local transaction semantics; not equivalent to PostgreSQL distributed operation.
6. OWASP. *Top 10 for Agentic Applications* (2025). https://genai.owasp.org/ — defense-in-depth context, not a compliance certification.
